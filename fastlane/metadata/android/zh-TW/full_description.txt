PodAura，整合 Podcast 收聽、RSS 閱讀和影音播放。

<b>主要功能</b>
<ul>
<li>訂閱 RSS，分組管理、搜尋文章並自動更新。</li>
<li>播放 Podcast 節目和本機影音檔案。</li>
<li>自動或批次下載節目，隨時離線播放。</li>
<li>支援背景播放、迷你播放器和子母畫面。</li>
<li>調整播放速度、選擇音軌和字幕，設定睡眠計時器。</li>
<li>建立播放清單，自由調整播放佇列順序。</li>
<li>透過日曆按日期瀏覽和播放節目。</li>
<li>閱讀完整文章，使用自行提供的翻譯服務 API key 翻譯內容。</li>
<li>批次管理已讀狀態、收藏和播放清單。</li>
<li>依訂閱和群組自訂更新通知。</li>
<li>透過 OPML 匯入和匯出訂閱。</li>
</ul>
