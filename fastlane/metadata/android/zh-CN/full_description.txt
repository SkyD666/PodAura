PodAura，将播客收听、RSS 阅读和音视频播放融为一体。

<b>主要功能</b>
<ul>
<li>订阅 RSS，分组管理、搜索文章并自动刷新。</li>
<li>播放播客节目和本地音视频文件。</li>
<li>自动或批量下载节目，随时离线播放。</li>
<li>支持后台播放、迷你播放器和画中画。</li>
<li>调整倍速、选择音轨和字幕，设置睡眠定时。</li>
<li>创建播放列表，自由调整播放队列顺序。</li>
<li>通过日历按日期浏览和播放节目。</li>
<li>阅读完整文章，使用自行提供的翻译服务 API key 翻译内容。</li>
<li>批量管理已读状态、收藏和播放列表。</li>
<li>按订阅和分组自定义更新通知。</li>
<li>通过 OPML 导入和导出订阅。</li>
</ul>
